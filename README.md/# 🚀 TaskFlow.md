# 🚀 TaskFlow

## 📖 Project Description

TaskFlow is a MERN Stack based Project Management System developed to manage projects and daily tasks efficiently. Users can register, login securely using JWT authentication, create projects, manage tasks, search records, and track task status from a dashboard.

---

## ✨ Features

- User Registration & Login
- JWT Authentication
- Dashboard with Live Statistics
- Create Project
- Edit Project
- Delete Project
- Search Project
- Create Task
- Edit Task
- Delete Task
- Search Task
- Update Task Status
- Responsive User Interface

---

## 🛠 Tech Stack

### Frontend
